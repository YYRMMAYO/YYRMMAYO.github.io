软件介绍

About

HelpDesk 是给不太懂电脑的 Windows 用户做的电脑助手。它不把所有功能塞进一个胖程序里，而是只保留一套最必要的外壳 —— 网速检测、软件卸载、系统诊断、系统清理、故障排除指南这些都做成独立插件，从 GitHub 仓库在线发现、下载、校验后加载，用不上的一律不占地方。

主程序是 WPF / .NET 8 自包含发布，用户不需要另装 .NET 运行时；安装包用 Inno Setup 6 编译，装到用户目录、全程不弹 UAC。插件是独立的 .NET 程序集，附带 metadata.json（含每个文件的 SHA-256）与仓库根的 plugins-index.json；下载后会校验再加载，插件与主程序版本互不牵连。

最新版本 v1.1.0（2026-09-24）新增了两个最常被问到的插件 —— 网速检测（下行 / 上行 / 延迟 / 抖动，多节点自动选择）与 软件卸载（调用注册表登记的官方卸载程序，卸载后按注册表记录的安装目录清理残留），并补齐了提权与插件分发链路。分发链路上还顺手把「索引更新了、文件还是旧的」这类 CDN 缓存问题按提交号取内容 + 校验的方式彻底解决。

面向的场景很朴素：家里长辈的电脑变慢、装了一堆不知道是什么的软件、网速忽快忽慢、想卸东西又怕删错 —— 每一件都给一个能看懂结果的小工具，而不是一堆需要自己判断的开关。

说明：仓库 Releases 上现有的安装包是 v1.0.0，v1.1.0 目前以源码 tag 形式发布；需要安装包时可用 tools/build-release.ps1 一条命令自建（要求 .NET 8 SDK 与 Inno Setup 6）。仓库暂未声明开源许可证。

HelpDesk is a PC helper for Windows users who aren't computer experts. Instead of stuffing every feature into one fat program it keeps a minimal shell — speed testing, app uninstalling, system diagnostics, cleanup and a troubleshooting guide all ship as separate plugins discovered, downloaded, verified and loaded from a GitHub repository on demand, so anything you don't need takes up no space.

The host is a self-contained WPF / .NET 8 app, so users never install a .NET runtime; the installer is built with Inno Setup 6, installs into the user directory and never raises a UAC prompt. Plugins are standalone .NET assemblies with a metadata.json (SHA-256 per file) plus a root plugins-index.json; every download is verified before loading, and plugin and host versions stay independent.

The latest release, v1.1.0 (2026-09-24), adds the two most requested plugins — network speed test (down / up, latency, jitter, automatic node selection) and app uninstaller (runs the official uninstaller registered for the app, then cleans leftovers from the recorded install directory) — and completes the elevation and plugin distribution path. The distribution work also kills the "new index, old file" CDN caching problem by fetching content per commit hash and verifying it.

The intended scenarios are plain: a relative's PC has gone slow, there's software nobody recognises, the connection is flaky, and uninstalling feels risky — each gets a small tool with a readable answer instead of a wall of switches to judge.

Note: the installer currently published under Releases is v1.0.0; v1.1.0 exists as a source tag for now. Build your own package with tools/build-release.ps1 (requires the .NET 8 SDK and Inno Setup 6). No open-source licence is declared for this repository yet.
