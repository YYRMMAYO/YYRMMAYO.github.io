软件介绍

About

OBS 排障助手 · 插件版是一个纯原生（C++ / Qt6）的 OBS Studio 前端插件：以「停靠面板」的形式直接嵌入 OBS 主窗口，为你做一次全面的「直播环境体检」——无需 .NET 运行库、不启动任何额外进程、全程只读检测。重启 OBS 后在菜单栏「停靠(Docks) → OBS 排障助手」即可打开。

最新版本 v2.7.0（2026-08-24 发布）新增录制健康与开播自检：录制路径真实写入预检（识别 OneDrive 云同步目录、按码率估算剩余可录时长）、损坏录制件扫描（0KB / 未收尾 MP4，可批量 MKV → MP4 抢救）、回放缓存快捷键排障，以及聚合以上各项的开播前一键自检——开播前 10 秒出结论。

把日志扔给 obsproject.com 之前，先让它在本地帮你把问题查清楚：日志分析对齐官方 Log Analyzer 规则集并支持 rules.json 热更新与在线订阅；崩溃转储就地解析出崩溃模块；「元凶插件」可一键禁用验证。

OBS Helper Plugin is a fully native (C++ / Qt6) front-end plugin for OBS Studio: it embeds a dock panel right inside the main window and runs a complete "livestream environment checkup" — no .NET runtime, no extra processes, strictly read-only detection. After installing, open it via the "Docks → OBS Helper" menu.

The latest release, v2.7.0 (2026-08-24), adds recording health & pre-flight self-check: real write-probe of the recording path (detects OneDrive sync folders, estimates remaining recordable time by bitrate), corrupt recording scan (0KB files / unfinalized MP4s with batch MKV → MP4 rescue), replay-buffer hotkey troubleshooting, and an aggregated one-click pre-flight check that delivers a verdict within 10 seconds before you go live.

Before uploading logs to obsproject.com, let it find the problem locally: log analysis aligns with the official Log Analyzer rule set (hot-updatable via rules.json + online subscription), crash dumps are parsed in place to identify the crashing module, and "culprit plugins" can be disabled with one click.

项目档案

Project Details

Architecture
手写导出 OBS 模块接口（不链接 libobs），运行期注册 Dock；log_rules / dump_check / record_check 等核心均可独立单测
Hand-written OBS module exports (no libobs linking), runtime dock registration; cores independently unit-testable
Safety
全程只读检测；所有检测逻辑均有 SEH 结构化异常防护，插件异常不会拖垮 OBS；报告导出自动脱敏推流密钥
Read-only checks; SEH-guarded logic so the plugin never takes OBS down; stream keys auto-sanitized in reports
Install
Setup 安装器自动探测 OBS 目录（含 Steam 版）；便携包手动安装；免管理员用户级安装（OBS 30.2+）；内置一键卸载
Setup installer auto-detects OBS (incl. Steam); portable zip; admin-free user-level install (OBS 30.2+); built-in uninstaller
i18n
界面默认跟随 OBS 语言设置，可手动切换（跟随 OBS / 中文 / English）；配色跟随宿主深浅色主题
UI follows the OBS language setting (overridable: Auto / 中文 / English); colors follow host theme
CI
推送 v* tag 自动构建发布；构建时运行规则引擎单元测试；可选代码签名
Tag-driven CI builds & releases; rule-engine unit tests run in build; optional code signing
