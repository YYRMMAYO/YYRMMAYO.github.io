软件介绍

About

《第101种理由》是一款数据驱动的 2.5D 恋爱叙事游戏。玩家通过点击推进剧情，部分节点会出现双选项互动；人物以 AI 生成立绘呈现，部分场景用 CSS 3D 做半立体叙述，带来「翻书般」的沉浸观感。

剧情改编自 9 段爱情故事，面向七夕上线。游戏完全离线可玩，进度自动保存在浏览器本地（localStorage），关闭页面后再次打开可继续游戏。

类型：2.5D 叙事视觉游戏 · 预计时长 20–30 分钟 · 运行平台：安卓浏览器 + Windows 浏览器（响应式）。

Love 101 is a data-driven 2.5D romance narrative game. Tap to advance the story; some nodes offer two-choice interactions. Characters are presented with AI-generated art, and some scenes use CSS 3D semi-stereoscopic narration for a book-like, immersive feel.

The story adapts 9 real love stories and launched for Qixi (Chinese Valentine's Day). It is fully playable offline; progress auto-saves to browser localStorage and resumes next time you open the page.

Genre: 2.5D narrative visual game · Length: 20–30 minutes · Platforms: Android browser + Windows browser (responsive).

运行与操作

Running & Controls

  • 运行方式：直接双击 index.html 即可游玩（保持 assets/ 与 js/ 相对结构完整）；也可用 python -m http.server 8080 起本地服务后访问。
  • Run: Double-click index.html to play (keep the assets/ and js/ structure intact); or serve locally with python -m http.server 8080.
  • 操作：点击 / 轻触屏幕推进剧情、跳过打字机、确认选项；选项按钮为双选一，影响细微文本，不改变结局。
  • Controls: Click / tap to advance the story, skip typewriter, confirm choices; choices are binary, tint subtle text, and do not change the ending.
  • 技术栈：纯前端 HTML / CSS / JavaScript，零运行时依赖；剧本以数据驱动方式组织在 js/data.js 中，便于扩展；打包壳位于 android/（Capacitor）与 src-tauri/（Tauri）。
  • Tech stack: Pure frontend HTML / CSS / JavaScript, zero runtime dependencies; the script is data-driven in js/data.js for easy extension; shells live in android/ (Capacitor) and src-tauri/ (Tauri).
