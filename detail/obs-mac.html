软件介绍

About

OBS 排障助手 macOS 版是一款面向直播新手的 OBS Studio 排障工具。知识库、排障指引与日志分析规则全部内嵌在应用里，不联网也能查、能分析、能控制 OBS。连上 OBS 后，可远程切换场景、录制与推流，并做一键体检。

本版本采用原生 Tauri v2（Rust）桌面壳 + Blazor WebAssembly 前端，功能与 Windows 版对齐，版本号同步至 v1.5.0。支持 macOS 11（Big Sur）及以上，提供 Apple Silicon 与 Intel 双架构 .dmg。注意：macOS 版不内置免费 AI 通道（仅本地规则引擎 + 自带云端 Key），保持最小依赖与最简发布。

OBS Helper (macOS) is an OBS Studio troubleshooting tool for livestreaming beginners. The knowledge base, troubleshooting guides and log-analysis rules are all embedded — you can search, analyze and control OBS without network. Once connected, remotely switch scenes, record, stream, and run a one-click health check.

Built with a native Tauri v2 (Rust) shell + Blazor WebAssembly frontend, it aligns with the Windows version (v1.5.0). Supports macOS 11 (Big Sur) and later, with .dmg for both Apple Silicon and Intel. Note: the macOS build ships no built-in free AI channel (local rule engine + your own cloud key only) to keep dependencies minimal.
