软件介绍

About

OBS 排障助手 macOS 版是一款面向直播新手的 OBS Studio 排障工具。212+ 条分步排障方案、日志分析规则、场景模板全部内嵌在应用里，不联网也能查、能分析、能控制 OBS。连上 OBS 后，可远程切换场景、录制与推流，并做一键体检。

本版本采用 Avalonia UI 单进程原生架构（替代早期 Tauri + WebAssembly 方案），功能与 Windows WPF 版完全对齐，版本号同步至 v2.1.0。支持 macOS 12 及以上，提供 Apple Silicon 与 Intel 双架构 .dmg。注意：macOS 版不内置免费 AI 通道（仅本地规则引擎 + 自带云端 Key），保持最小依赖与最简发布。

OBS Helper (macOS) is an OBS Studio troubleshooting tool for livestreaming beginners. 212+ step-by-step troubleshooting solutions, log-analysis rules and scene templates are all embedded — you can search, analyze and control OBS without network. Once connected, remotely switch scenes, record, stream, and run a one-click health check.

Built with a native Avalonia UI single-process architecture (replacing the earlier Tauri + WebAssembly approach), it aligns feature-for-feature with the Windows WPF edition (v2.1.0). Supports macOS 12 and later, with .dmg for both Apple Silicon and Intel. Note: the macOS build ships no built-in free AI channel (local rule engine + your own cloud key only) to keep dependencies minimal.
