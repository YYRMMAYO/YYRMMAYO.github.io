软件介绍

About

CookieLuncher（Cookie 启动器）是一个本地运行的中文命令行小工具：把各网站的登录 Cookie 加密保存在本机，需要时一键注入浏览器打开网站；也可以直接打开可见浏览器让你手动登录（含验证码），回来按回车就把全部有效 Cookie 采集下来。仓库目录名是 CookiesLuncher，程序内统一叫 CookieLuncher。

它解决的问题很具体：不想在每台设备、每个浏览器里重复登录，也不想把 Cookie 明文贴在脚本里。所有网站的 Cookie 加密写进单个 cookies.enc，明文永不落盘，密码错了就解不开；主菜单的导出还额外加了一道二重导出密码（只存哈希），避免别人拿到文件就能导。

启动流程是：先建一个临时用户数据目录 → Playwright 启动浏览器并把 Cookie 注入（Chromium 原生加密写盘，登录态可靠）→ 页面加载完成后退出 Playwright，由程序直接拉起同一个浏览器的独立进程 → 你正常用浏览器，关闭窗口后程序监控到全部进程退出，自动删除临时目录，不留登录态。内置的 Thorium 后端自带 H.264 / AAC 专有编解码，普通 B 站视频可直接播放；会员 / DRM 视频则切到本机 Edge / Chrome 后端。

另一个用途是配合 GitHub Action 的保活项目：一键导出只含密文的 action_config_output.json 与控制台打印的 Fernet 密钥（存进仓库 Secret，例如 COOKIE_FERNET_KEY），定时任务就能用同一份登录态去保活，不需要把 Cookie 明文放进仓库。

说明：需要 Python 3.10+ 与 pip install -r requirements.txt（首次安装依赖要联网）；Thorium 后端需自行从其 Releases 下载并放到 external_browsers\thorium-win64\。仓库暂未声明开源许可证。

CookieLuncher is a small local Chinese-language CLI: it encrypts and stores per-site login cookies on your own machine and injects them into a browser on demand; it can also open a visible browser so you log in yourself (captcha included) and collect every valid cookie when you press Enter. The repository folder is still called CookiesLuncher, while the program calls itself CookieLuncher.

The problem it solves is concrete: you don't want to log in again on every device and browser, and you certainly don't want cookies sitting in plain text inside a script. All sites go into a single encrypted cookies.enc — plaintext never touches disk, and a wrong password simply can't decrypt it. Exporting from the menu adds a second, hash-only export password so that holding the file isn't enough.

Launching works like this: create a temporary profile, have Playwright start the browser and inject the cookies (Chromium's own encryption writes them to disk, so the session holds), then quit Playwright and relaunch the same browser as a standalone process. You browse normally, and once every process exits the tool deletes the temporary profile, leaving no session behind. The bundled Thorium backend carries the proprietary H.264 / AAC codecs so ordinary Bilibili videos play; member or DRM content switches to your local Edge / Chrome.

Its other job is feeding a GitHub Action keep-alive project: one click exports a ciphertext-only action_config_output.json plus a Fernet key printed to the console (store it as a repository secret such as COOKIE_FERNET_KEY), so the scheduled job can reuse the same login state without any plain-text cookies in the repository.

Note: requires Python 3.10+ and pip install -r requirements.txt (the first install needs a network connection); the Thorium backend must be downloaded from its own releases into external_browsers\thorium-win64\. No open-source licence is declared for this repository yet.

Project Details

Environment
Windows + Python 3.10 及以上；pip install -r requirements.txt 后 python main.py 启动
Windows with Python 3.10+; run pip install -r requirements.txt, then python main.py
Storage
Cookie 密文存 cookies.enc；访问密码首次启动时设定（至少 6 位），同时用于登录程序与加密
Ciphertext lives in cookies.enc; the access password is set on first run (6+ characters) and serves both as login and as the encryption key
Capture
Playwright 驱动浏览器注入 / 采集；采集与启动都用独立临时目录，结束自动查杀残留进程并删除
Playwright drives injection and capture, each in its own temporary profile that is cleaned up (stray processes included) when finished
Export
导出 Fernet 对称加密的 Cookie 清单；密钥只在控制台打印一次，需自行存进 GitHub Secret
Exports a Fernet-encrypted cookie list; the key is printed to the console once and must be stored as a GitHub secret

Thorium is an independent community project unrelated to this tool's author; the bundled Thorium binaries follow Thorium's own licence
