About

GuideCraft 是一款引导式 AI 助手：像资深技术顾问一样，通过多轮对话帮你把模糊想法变成可运行的 Python 自动化脚本。不会编程也能做自动化——产品、运营、创业者，把想法说出来，剩下的交给 GuideCraft。

AI 主动提问，围绕 8 个需求维度逐步澄清（每轮最多 2 问），对话顶部实时显示收集进度；信息齐备后自动输出结构化中文需求文档与单文件 Python 脚本（含中文注释、main 入口、依赖清单）。生成代码可一键沙盒试运行（AST 预检 + 子进程隔离 + 超时保护），支持「加上错误处理」这类自然语言迭代，AI 会自动更新代码。

会话与产物保存在本机 SQLite，重启可恢复；API Key 经 Windows DPAPI 加密，数据链 AES-256-GCM 字段级加密。支持千问 / DeepSeek / OpenAI / Claude / Gemini / GLM / Kimi / MiniMax / 混元 / Grok / Mistral 等主流模型及自定义 OpenAI 兼容端点。

GuideCraft is a guided AI assistant that, like a senior technical consultant, turns vague ideas into runnable Python automation scripts through multi-turn conversation. No coding skills required — product people, operators and founders describe their idea, and GuideCraft handles the rest.

The AI proactively asks questions to clarify 8 requirement dimensions (max 2 questions per round), showing collection progress at the top of the chat. Once enough info is gathered, it outputs a structured requirement document and a single-file Python script (Chinese comments, main entry, dependency list). Generated code can be test-run in a local sandbox with one click (AST pre-check + child-process isolation + timeout). Iterate naturally — "add error handling" — and the AI updates the code.

Sessions and artifacts persist in local SQLite; API keys are encrypted with Windows DPAPI and data uses AES-256-GCM field-level encryption. Supports Qwen / DeepSeek / OpenAI / Claude / Gemini / GLM / Kimi / MiniMax / Hunyuan / Grok / Mistral and custom OpenAI-compatible endpoints.
