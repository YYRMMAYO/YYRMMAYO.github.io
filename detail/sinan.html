软件介绍

About

司南工具箱是一款完全免费、非盈利的 Windows 电脑辅助工具，专注于系统检测、清理优化、网络诊断与故障排查。本地运行、操作安全，绝不自动删除你的个人文件。本软件使用 AI 技术进行开发，人工进行维护。

从 v5.3.0 起全面转向极简设计，v5.6.0 将导引栏移至右侧：界面统一采用「中文首字徽标」（如 清、启、网），去除花哨装饰；首页为渐变欢迎条 + 分组功能卡片。提供关怀模式，可将界面整体缩放 85%–140%，方便老人 / 低视力 / 远距离使用。内置多套主题（默认 / 绿 / 橙 / 紫 / 粉 / 青 / 星空 / 极光）与 AI 智能助手（调用系统工具前需确认）。

Sinan Toolbox is a completely free, non-profit Windows utility focused on system detection, cleanup & optimization, network diagnostics and troubleshooting. It runs locally and is safe — it never deletes your personal files automatically. Developed with AI assistance and maintained by humans.

Since v5.3.0 the design went minimalist; v5.6.0 moved the navigation rail to the right: modules use Chinese initial-letter badges and the home page features a gradient greeting bar plus grouped function cards. A Care Mode scales the whole UI from 85% to 140% for elderly / low-vision / distance viewing. It ships multiple themes (Default / Green / Orange / Purple / Pink / Cyan / Starry / Aurora) and a built-in AI assistant (confirmation required before invoking system tools).
