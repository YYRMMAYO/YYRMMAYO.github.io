软件介绍

About

司南工具箱是一款完全免费、非盈利的 Windows 电脑辅助工具，专注于系统检测、清理优化、网络诊断与故障排查。本地运行、操作安全，绝不自动删除你的个人文件。本软件使用 AI 技术进行开发，人工进行维护。

从 v5.9.0 起重构为「印谱 · 隔页标签」视觉世界：分区色板地面（首页靛蓝、系统工具氧化橙、设置紫罗兰）随功能切换，左侧阶梯标签导轨如说明书隔页签，奶白醋酸酯阅读叶卡片替代弥散玻璃影；v6.0.0 新增「WiFi 密码」模块，一键查看本机已存无线网明文密码，并精简与 WIN 助手重复的模块。保留关怀模式（界面整体缩放 85%–140%）与多套主题（默认 / 绿 / 橙 / 紫 / 粉 / 青 / 星空 / 极光）。

Sinan Toolbox is a completely free, non-profit Windows utility focused on system detection, cleanup & optimization, network diagnostics and troubleshooting. It runs locally and is safe — it never deletes your personal files automatically. Developed with AI assistance and maintained by humans.

Since v5.9.0 the UI was rebuilt as the "seal-album · indexed-tab" visual world: a zone-colored ground (indigo on home, oxidized-orange for system tools, violet for settings) shifts with the section, a left stepped-tab rail acts like a book's index tabs, and milky acetate reading-leaf cards replace the diffuse glass shadows. v6.0.0 adds a "WiFi Password" module to reveal saved wireless passwords at one click and trims modules duplicating the WIN assistant. The Care Mode (85%–140% UI scaling) and multiple themes (Default / Green / Orange / Purple / Pink / Cyan / Starry / Aurora) remain.
