软件介绍

About

AIStudioHub 是一款简洁、开源的 Windows 桌面应用，汇集 AI 视频制作、网页制作、图像生成、音乐音频与文本大模型等主流平台资源，并内置精选中文教程，离线可读。

资源库按五大分类收录 181 个主流与特色平台（含 GitHub 热门开源 AI 工具），各工具卡片与详情页自动展示官网官方图标（共 176 个），未收录图标时回退品牌色首字块。内置 181 篇精华中文教程（核心步骤 + 可直接复制的提示词模板），覆盖建站、视频、绘画、音乐、编程与 Agent 开发全流程。

另有智能体与 Skill 专区，精选 32 个 AI Agent 框架（AutoGPT / MetaGPT / CrewAI / AutoGen / OpenHands / Claude Code / Codex / Gemini CLI / Qwen Code / Manus / Devin 等）与「AI 编码智能体助手」「插件蒸馏」等 Skill 库，每个条目均含教程介绍与版权 / 开源协议信息。

AIStudioHub is a clean, open-source Windows desktop app that aggregates mainstream AI platforms — video, web, image, music & audio, and LLMs — with curated Chinese tutorials, readable offline.

The library covers 181 mainstream & featured platforms across five categories (including hot open-source AI tools on GitHub). Each card and detail page shows the official icon automatically (176 icons in total), falling back to a brand-color initial block when missing. It ships 181 curated Chinese tutorials (key steps + copy-ready prompt templates) covering website building, video, art, music, coding and Agent development.

An Agent & Skill zone features 32 selected AI Agent frameworks (AutoGPT / MetaGPT / CrewAI / AutoGen / OpenHands / Claude Code / Codex / Gemini CLI / Qwen Code / Manus / Devin and more) plus "AI Coding Agent Assistant" and "Skill Distillation" libraries — each entry with tutorial and license information.
