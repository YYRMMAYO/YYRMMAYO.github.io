About

OBS帮助助手（原「OBS 排障助手」）是一款面向直播新手的 OBS Studio 排障工具，纯离线可用：212 条问题知识库、排障指引与日志分析规则全部内嵌在程序里，不联网也能查。连上 OBS 之后，还能远程控制场景、录制与推流，并做一键体检。

最新版本 V2.9.6（2026-10-05 发布）是一次「改名 + 换图标 + 对齐文档」的发布：应用正式更名为 「OBS帮助助手」（英文侧仍是 OBS Helper），窗口标题、托盘提示与通知、新手引导、诊断报告署名与安装向导全部换名；应用图标也与仓库封面统一成同一枚（深色圆角底 + 显示器 + 健康波形 + 录制指示点 + 体检对勾），并为 16 / 24 / 32 px 单独重绘。改名不牵动升级路径 —— AppId、OBS_Helper.exe、%LocalAppData%\OBS_Helper\ 与 Release 资产命名都刻意保持不变，老用户升级后安装目录、设置与密钥一切照旧。

往前几版把「能不能录、录得稳不稳」这条链补齐了：V2.9.4 首页新增「简单录像」卡，三档预设（快速录像 / 会议网课 / 游戏高码率）只决定「录什么」，OBS 没启动时还能由本工具先整备份 basic.ini、拉起 obs64.exe、等 obs-websocket 就绪后自动开录；录制中显示已录时长与剩余可录，录完读回文件大小并可一键无损转封装为 MP4。V2.9.3 把随包离线内容（知识库 / 插件广场 / 场景模板 / 排障指引）做成中英双份，并把运行环境兼容到 Windows 7 SP1；V2.9.2 起界面与安装向导支持中英即时切换（1670 条文案键，默认简体中文）。

技术侧仍是原生 WPF + .NET 10 的单目录自包含发布，零 NuGet、无 WebView2；单元测试规模从 381 项扩到 626 项，Headless 自检 22 项。这是原 Blazor WebAssembly + WebView2 版本的原生 WPF 重构：冷启动直接起窗口、无需安装 WebView2 与 .NET 运行时；V2.1 起支持增量更新与知识库独立更新：更新只下载变更文件（2.0 → 2.1.1 增量包仅 1.27MB），问题库可脱离应用单独升级。

OBS帮助助手 (formerly "OBS 排障助手") is a troubleshooting tool for OBS Studio designed for livestreaming beginners. It works fully offline: a 212-entry knowledge base, troubleshooting guides and log-analysis rules are all embedded. Once connected to OBS, you can remotely control scenes, recording and streaming, and run a one-click health check.

The latest release, V2.9.6 (2026-10-05), is a rename, icon and documentation pass: the app is now called "OBS帮助助手" (the English name stays OBS Helper), with the window title, tray tooltip and notifications, onboarding, report byline and installer all following. The app icon now matches the repository artwork (dark rounded tile, monitor, health waveform, record dot and check badge) and was redrawn separately at 16 / 24 / 32 px. None of this touches the upgrade path — AppId, OBS_Helper.exe, %LocalAppData%\OBS_Helper\ and the release asset names are deliberately unchanged, so existing users keep their install directory, settings and secrets.

Earlier releases filled in the "can you record, and does it hold" chain: V2.9.4 added a "Simple recording" card where three presets (quick, meeting / lecture, high-bitrate game) decide only what to record — and if OBS isn't running the tool backs up basic.ini, launches obs64.exe and starts recording once obs-websocket is ready. While recording you see elapsed and remaining time, and when it stops the file size is read back with one-click lossless remux to MP4. V2.9.3 shipped the bundled offline content (knowledge base, plugin square, scene templates, guides) in both Chinese and English and extended support down to Windows 7 SP1; since V2.9.2 the UI and installer switch between Chinese and English on the fly (1670 string keys, Simplified Chinese by default).

Under the hood it remains a native WPF + .NET 10 self-contained single-folder build with no NuGet and no WebView2; the unit-test suite grew from 381 to 626 tests, alongside 22 headless self-check items. This is a native WPF rewrite of the former Blazor WebAssembly + WebView2 version — cold start opens the window directly, with no WebView2 or .NET runtime to install. Since V2.1 it supports incremental updates and standalone knowledge-base updates: only changed files are downloaded (the 2.0 → 2.1.1 delta pack is just 1.27MB) and the question library can be upgraded on its own.
