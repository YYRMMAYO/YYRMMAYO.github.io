软件介绍

About

OBS 排障助手是一款面向直播新手的 OBS Studio 排障工具，纯离线可用：110 条问题知识库、排障指引与日志分析规则全部内嵌在程序里，不联网也能查。连上 OBS 之后，还能远程控制场景、录制与推流，并做一键体检。

这是原 Blazor WebAssembly + WebView2 版本的原生 WPF 重构，功能一比一对齐，但去掉了浏览器内核这一层：冷启动直接起窗口、自包含单目录发布、无需安装 WebView2 与 .NET 运行时。V2.1 起支持增量更新与知识库独立更新：更新只下载变更文件（2.0 → 2.1.1 增量包仅 1.27MB），问题库可脱离应用单独升级。

OBS Helper is a troubleshooting tool for OBS Studio designed for livestreaming beginners. It works fully offline: a 110-entry knowledge base, troubleshooting guides and log-analysis rules are all embedded. Once connected to OBS, you can remotely control scenes, recording and streaming, and run a one-click health check.

This is a native WPF rewrite of the former Blazor WebAssembly + WebView2 version — features are aligned 1:1, but the browser-kernel layer is gone: cold start opens the window directly, self-contained single-folder publishing, no WebView2 or .NET runtime needed. Since V2.1 it supports incremental updates and standalone knowledge-base updates: only changed files are downloaded (the 2.0 → 2.1.1 delta pack is just 1.27MB).
