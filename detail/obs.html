软件介绍

About

OBS 排障助手是一款面向直播新手的 OBS Studio 排障工具，纯离线可用：212 条问题知识库、排障指引与日志分析规则全部内嵌在程序里，不联网也能查。连上 OBS 之后，还能远程控制场景、录制与推流，并做一键体检。

最新版本 V2.9.1（2026-09-26 发布）把新手引导做成「跳转式引导」——每一步自动把界面切到对应页面（控制台 / 首页 / 诊断 / 搭建）再讲解，卡片挪到右下角、遮罩压到约 17%，真正做到边看界面边讲；同时新增官方 OBS 下载入口：只指向 obsproject.com 与官方 GitHub，安装包直链经 GitHub API 取当前稳定版，避开「下载站」仿冒包，并提示用户自行核对数字签名。

V2.9.0 带来首启四步新手教程与插件广场全量复核（目录 v1.4：57 条逐一实测，剔除 8 个已死条目、新增 8 个活跃条目、标注「维护放缓」），并针对 OBS 32.2.2 修掉数处静默失效：日志头字段（CPU / 内存 / 帧率 / 码率）在真实日志里全部解析为空、显卡解析错位导致双显卡告警失效、实时日志尾随预警按 .log 找文件而 OBS 会话日志是 .txt。

这是原 Blazor WebAssembly + WebView2 版本的原生 WPF 重构：冷启动直接起窗口、自包含单目录发布、无需安装 WebView2 与 .NET 运行时。V2.1 起支持增量更新与知识库独立更新：更新只下载变更文件（2.0 → 2.1.1 增量包仅 1.27MB），问题库可脱离应用单独升级。

OBS Helper is a troubleshooting tool for OBS Studio designed for livestreaming beginners. It works fully offline: a 212-entry knowledge base, troubleshooting guides and log-analysis rules are all embedded. Once connected to OBS, you can remotely control scenes, recording and streaming, and run a one-click health check.

The latest release, V2.9.1 (2026-09-26), turns onboarding into a jump-style guided tour: each step navigates the app to the matching page (console / home / diagnosis / setup) before explaining it, with a compact card in the corner and a lightened backdrop — you learn the UI while looking at it. It also adds an official OBS download entry that only points to obsproject.com and the official GitHub, resolving the current stable installer through the GitHub API to steer users away from look-alike "download site" bundles, plus a tip to verify the digital signature yourself.

V2.9.0 brought the four-step getting-started tutorial and a full audit of the plugin square (catalog v1.4: all 57 entries re-tested, 8 dead entries removed, 8 active ones added, "slowing" ones flagged), and fixed several silent failures under OBS 32.2.2: log header fields (CPU / memory / FPS / bitrate) parsing empty on real logs, GPU mis-parsing that disabled the dual-GPU alert, and live log tailing looking for .log while OBS writes .txt session logs.

This is a native WPF rewrite of the former Blazor WebAssembly + WebView2 version: cold start opens the window directly, self-contained single-folder publishing, no WebView2 or .NET runtime needed. Since V2.1 it supports incremental updates and standalone knowledge-base updates — only changed files are downloaded (the 2.0 → 2.1.1 delta pack is just 1.27MB).
