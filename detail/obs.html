软件介绍

About

OBS 排障助手是一款面向直播新手的 OBS Studio 排障工具，纯离线可用：149 条问题知识库、排障指引与日志分析规则全部内嵌在程序里，不联网也能查。连上 OBS 之后，还能远程控制场景、录制与推流，并做一键体检。

最新版本 V2.8.2「守护与体检」（2026-08-26 发布）带来三层守护与新体检：录制守护监控断连 / 心跳超时 / 重连确认，直播中录制静默失败立刻托盘强提醒；实时日志尾随预警在掉帧、编码过载、断流发生的当下即时告警，不用等下播翻日志；工具箱新增黑屏专项、音频设备深度、虚拟摄像头三张体检卡片，并支持已知风险插件黄标提示。

这是原 Blazor WebAssembly + WebView2 版本的原生 WPF 重构：冷启动直接起窗口、自包含单目录发布、无需安装 WebView2 与 .NET 运行时。V2.1 起支持增量更新与知识库独立更新：更新只下载变更文件（2.0 → 2.1.1 增量包仅 1.27MB），问题库可脱离应用单独升级。

OBS Helper is a troubleshooting tool for OBS Studio designed for livestreaming beginners. It works fully offline: a 149-entry knowledge base, troubleshooting guides and log-analysis rules are all embedded. Once connected to OBS, you can remotely control scenes, recording and streaming, and run a one-click health check.

The latest release, V2.8.2 "Guardian & Checkup" (2026-08-26), adds three-layer protection and new checkups: a recording watchdog (disconnect / heartbeat-timeout / reconnect-confirm alerts) that tray-notifies you the moment recording silently fails mid-stream; real-time log tailing alerts for frame drops, encoder overload and disconnects as they happen; plus three new toolbox cards — black-screen, audio-device and virtual-camera deep checks — and yellow-flag warnings for known-risky plugins.

This is a native WPF rewrite of the former Blazor WebAssembly + WebView2 version: cold start opens the window directly, self-contained single-folder publishing, no WebView2 or .NET runtime needed. Since V2.1 it supports incremental updates and standalone knowledge-base updates — only changed files are downloaded (the 2.0 → 2.1.1 delta pack is just 1.27MB).
