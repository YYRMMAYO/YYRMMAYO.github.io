软件介绍

About

OBS帮助助手（原「OBS 排障助手」）是一款面向直播新手的 OBS Studio 排障工具，纯离线可用：212 条问题知识库、排障指引与日志分析规则全部内嵌在程序里，不联网也能查。连上 OBS 之后，还能远程控制场景、录制与推流，并做一键体检。

最新版本 V3.0.0（2026-10-06 发布）改的是「底子」：所有会写用户文件的动作（设置、知识库、模板、录制归档）改走同一条事务通道 —— 写前快照 + 原子替换 + 校验读回，中途失败自动回滚；写入路径一律加越界护栏，OBS 密码等机密独立加密存储。这一版还补上无障碍适配（键盘焦点可见、读屏实时区域、跟随系统高对比与文本大小），并让 Windows 7 兼容构建真正连得上 OBS（支持旧协议 obs-websocket 4.x，默认端口 4444，数据目录独立为 %LocalAppData%\OBS_Helper_Win7，与主构建互不影响）。

新功能上：回放缓存一键存片（托盘与热键保存「刚才那段」）、简单开播（按下去之前先查服务器与串流密钥填没填，并提示上行拥塞、丢帧与同时录制）、录制档案 + 录制中打点（导出章节、批量无损转 MP4）、配置回收站（OBS 配置的每次改写都留副本，可一键放回原位）、开播前体检 + 一键处方，以及自建知识库条目与拼音首字母 / 同义词搜索增强。

运行环境分两条线：主构建面向 Windows 10 / 11（.NET 10），另有 Windows 7 SP1 兼容构建（.NET 6，最后一个支持 Win7 的版本；安装包 / 便携包 / 增量包都带 _win7 后缀，按系统选一个即可）。两者都是原生 WPF 的单目录自包含发布，零 NuGet、无 WebView2，也无需另装 .NET 运行时。单元测试从 630 项扩到 1209 项全部通过，无界面自检 26 项，主构建与 Win7 兼容构建各跑一次。

往前几版把「能不能录、录得稳不稳」这条链补齐了：V2.9.4 首页新增「简单录像」卡，三档预设（快速录像 / 会议网课 / 游戏高码率）只决定「录什么」，OBS 没启动时还能先备份 basic.ini、拉起 obs64.exe、等 obs-websocket 就绪后自动开录；V2.9.6 正式更名为「OBS帮助助手」（AppId、安装目录与数据目录刻意不动）；V2.9.3 把随包离线内容做成中英双份；V2.9.2 起界面与安装向导支持中英即时切换（默认简体中文）。更新仍是增量更新：只下载变更文件并逐文件校验 SHA-256，失败自动回退整包，问题库也能脱离应用单独升级。

OBS帮助助手 (formerly "OBS 排障助手") is a troubleshooting tool for OBS Studio designed for livestreaming beginners. It works fully offline: a 212-entry knowledge base, troubleshooting guides and log-analysis rules are all embedded. Once connected to OBS, you can remotely control scenes, recording and streaming, and run a one-click health check.

The latest release, V3.0.0 (2026-10-06), rebuilds the foundation: every action that writes user files (settings, knowledge base, templates, recording archive) now goes through one transaction channel — snapshot before writing, atomic replace, verify by reading back, with automatic rollback on failure; all write paths carry boundary guardrails, and secrets such as the OBS password are stored encrypted and separately. This release also adds accessibility work (visible keyboard focus, live regions for screen readers, following the system high-contrast theme and text size) and makes the Windows 7 build actually able to connect to OBS (legacy obs-websocket 4.x, default port 4444, its own data directory %LocalAppData%\OBS_Helper_Win7, fully independent of the main build).

New features: one-click replay-buffer clip saving (tray and hotkey for "the bit that just happened"), simple stream start (checks server and stream key before you press it, and warns about uplink congestion, dropped frames and simultaneous recording), a recording archive with in-recording markers (chapter export, batch lossless MP4 remux), a config recycle bin (every rewrite of the OBS config keeps a copy you can put back in one click), a pre-stream checkup with one-click prescription, plus your own knowledge-base entries and pinyin-initial / synonym search.

Support comes in two lines: the main build targets Windows 10 / 11 (.NET 10), with a separate Windows 7 SP1 compatible build (.NET 6 — the last .NET that supports Win7; its installer, portable and delta packages carry the _win7 suffix, so pick the one matching your system). Both are self-contained single-folder native WPF builds with no NuGet and no WebView2, and neither needs a separate .NET runtime. The unit-test suite grew from 630 to 1209 tests, all passing, alongside 26 headless self-check items run once per build.

Earlier releases filled in the "can you record, and does it hold" chain: V2.9.4 added a "Simple recording" card where three presets (quick, meeting / lecture, high-bitrate game) decide only what to record — and if OBS isn't running the tool backs up basic.ini, launches obs64.exe and starts recording once obs-websocket is ready. V2.9.6 renamed the app to "OBS帮助助手" (deliberately leaving AppId, the install directory and the data directory untouched), V2.9.3 shipped the bundled offline content in both Chinese and English, and since V2.9.2 the UI and installer switch languages on the fly (Simplified Chinese by default). Updates remain incremental: only changed files are downloaded and each is verified with SHA-256, falling back to the full package if something doesn't match — and the question library can be upgraded on its own.
