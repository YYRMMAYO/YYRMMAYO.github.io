软件介绍

About

OBS帮助助手（原「OBS 排障助手」）是一款面向直播新手的 OBS Studio 排障 / 录制 / 推流助手，纯离线可用：208 条问题的知识库、排障指引与日志分析规则全部内嵌在程序里，不联网也能查。连上本机 OBS 之后还能一键体检、远程控制场景与录制推流，把「配好 OBS」到「开始录制」收进首页一张卡。零 NuGet、无 WebView2 的原生 WPF，自包含单目录，秒开。

最新版本 V3.5.3（2026-10-31 发布，与 X 系列 X1031Y3 内容一致，仅应用图标不同）把插件广场与开源依赖中心真正做成「应用内一键配置」：精选插件卡片或粘贴 owner/repo 就能查最新 Release → 下载 → SHA-256 校验 → 安全解压安装；FFmpeg / rclone / whisper / MediaMTX 也能在应用内一键装好并自动填入路径。本机检测到的插件不再只读 —— 可以卸载（整目录移进备份目录，不硬删）、用户级 ⇄ 全局级迁移、接管管理。手机摄像头补齐推流二维码、推流检测与一键防火墙放行，并支持 MediaMTX WebRTC 视频监看与 OBS WHIP 推流地址。同时修掉了 GitHub Release 资产 302 到新 CDN 后被白名单拒绝、导致插件与依赖下载全部失败的问题。

再往前一版 V3.5.2 修的是「状态可信度」：OBS 在停止事件之后仍会短暂把 outputActive 报成 true，旧实现把这次查询写回，于是停止录制后电脑端和手机端一直显示「录制中 / 直播中」；现在状态事件是权威来源，查询只补时长与字节数，另有每 3 秒一次的轻量对账。批量状态查询也改用 obs-websocket 5.x 的 RequestBatch（op 8 / 9），连接后的录制、推流、虚拟摄像头状态与音量重新实时刷新。

V3.3.0 – V3.5.0 把它从「排障工具」长成一套直播工作台：虚拟直播（Live2D 一键配置 → 10 套直播间模板 → 16 个国内外平台开播引导）、无障碍模式 / 老年模式（全局令牌：字号、导航宽度、控件最小高度、焦点框粗细）、3.5 形态的界面（壁纸覆盖整窗 + 毛玻璃导航 + 可调圆角 / 面板不透明度 / 界面字体、启动动画）、小窗控制（切场景、静音、存回放、提词器、工作室模式）以及手机远程改提词稿。

V3.4.0 则是「手机联动」那一版：扫码配对后手机可遥控 / 监看 / 提词 / 补光 / 快传，还能当 Wi-Fi 摄像头与麦克风进 OBS（多机位 2–4 路、最多 3 路只读监看、远程嘉宾房间）；同时交付弹幕聚合（B 站 / Twitch 只读）、本地实时字幕（WASAPI → VAD → whisper.cpp）、复盘报告与切片竖屏导出、多平台转推与 rclone 归档。所有局域网能力默认关闭、只绑私网、可随时撤销。

运行环境分两条线：主构建面向 Windows 10 / 11（.NET 10），另有 Windows 7 SP1 兼容构建（.NET 6，支持旧协议 obs-websocket 4.x，数据目录独立为 %LocalAppData%\OBS_Helper_Win7）。发布通道也分两条：V 系列（V3.5.3，稳定优先）与 X 系列（X + 日期码，如 X1031，同一天再版追加 Y1 / Y2 / Y3，配 X 专属图标）；两套构建共用安装目录、程序集名与数据目录，更新检查各认自己的标签，互不打扰。更新一律走增量更新：只下载变更文件并逐文件校验 SHA-256，失败自动回退整包，知识库与插件目录还能脱离应用单独升级。

OBS帮助助手 (formerly "OBS 排障助手") is an OBS Studio troubleshooting, recording and streaming assistant for livestreaming beginners. It works fully offline: a 208-entry knowledge base, troubleshooting guides and log-analysis rules are all embedded, so searching still works with no network. Once connected to your local OBS it runs one-click health checks and controls scenes, recording and streaming remotely, and the whole path from "configure OBS" to "start recording" fits on one home-page card. Native WPF with zero NuGet packages and no WebView2, self-contained in a single folder, cold-starts instantly.

The latest release, V3.5.3 (2026-10-31, feature-identical to the X-series X1031Y3 apart from the app icon), turns the plugin square and dependency centre into genuine in-app one-click setup: pick a curated plugin card or paste owner/repo to look up the latest release, download, verify SHA-256 and unpack a safe install; FFmpeg, rclone, whisper and MediaMTX install the same way and fill their paths in automatically. Locally detected plugins are no longer read-only — uninstall (the whole folder moves into a backup directory instead of being deleted), migrate between user-level and global-level, or take one over. Phone cameras gained a streaming QR code, stream detection and one-click firewall allowance, plus WebRTC monitoring through MediaMTX and an OBS WHIP ingest address. This release also fixes the GitHub release assets being rejected once they 302-redirect to a new CDN, which had broken every plugin and dependency download.

The release before it, V3.5.2, was about trustworthy state: OBS keeps reporting outputActive=true briefly after the stop event, and the old code wrote that query result back — so after stopping a recording both the desktop and the phone kept showing "recording / live". State events are now authoritative and queries only fill in duration and byte counts, with a light reconciliation every three seconds. Batch state queries moved to obs-websocket 5.x RequestBatch (op 8 / 9), so record, stream, virtual-camera and volume states refresh live again after connecting.

V3.3.0 through V3.5.0 grew it from a troubleshooting tool into a full streaming workbench: virtual streaming (one-click Live2D setup → 10 room templates → guides for 16 Chinese and international platforms), accessibility and senior modes (global tokens for font size, nav width, control height and focus-ring weight), a 3.5-era interface (wallpaper across the whole window, frosted-glass navigation, adjustable corner radius / panel opacity / UI font, launch animation), a mini window (switch scenes, mute, save replays, teleprompter, studio mode) and phone-side teleprompter script editing.

V3.4.0 was the phone-link release: scan to pair, then use the phone to control, monitor, prompt, light and send files — or as a Wi-Fi camera and microphone into OBS (2–4 camera positions, up to 3 read-only monitors, remote guest rooms). It also delivered chat aggregation (Bilibili / Twitch, read-only), local live captions (WASAPI → VAD → whisper.cpp), review reports with highlight clipping and vertical export, plus multi-platform relay and rclone archiving. Every LAN feature is off by default, binds to private networks only, and can be revoked at any moment.

Support comes in two lines: the main build targets Windows 10 / 11 (.NET 10), with a separate Windows 7 SP1 compatible build (.NET 6 that speaks legacy obs-websocket 4.x from its own data directory, %LocalAppData%\OBS_Helper_Win7). Releases come in two channels as well: the V series (V3.5.3, stability first) and the X series (X plus an MMdd date code such as X1031, with Y1 / Y2 / Y3 suffixes for repeat releases on the same day, and its own icon). Both share the install directory, assembly name and data directory while each update check only honours its own tags. Updates are incremental: only changed files are downloaded and each is verified with SHA-256, falling back to the full package if something doesn't match — and the knowledge base and plugin catalog can update on their own without a release.
