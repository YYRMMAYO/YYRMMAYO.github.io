关于本项目

「YYRMM的软件库」是个人软件作品的集中展示站点，收录第101种理由、AIStudioHub、OBS 系列三个版本（Windows 版 OBS帮助助手、macOS 与 OBS 插件版 OBS 排障助手）以及司南工具箱等项目。 各软件均配有独立的详细介绍页；「更新记录」由脚本自动同步自对应仓库的 GitHub Releases / Tags，与正式发布版本保持一致。 「资料下载」板块另收录由 AI 整理与编写的学习资料合集，可通过云盘直接下载。

A centralized showcase for my software — Love 101, AIStudioHub, the OBS Helper family (Windows / macOS / OBS plugin) and Sinan Toolbox. Every project has a dedicated detail page; changelogs are synced automatically from each repository's GitHub Releases / Tags and stay in step with official versions. The Downloads section also collects study materials organized and written with the help of AI, downloadable straight from a cloud drive.
